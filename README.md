# Huggit

> 블로그 글도 커밋으로 남기고, 잔디도 심자!  
> Huggit은 개발자의 꾸준한 성장 습관을 도와주는 커밋 보조 앱입니다.

---

## 📱 주요 기능

### 1. 블로그 글 커밋  
GitHub 계정으로 로그인한 후, Velog 또는 Tistory 닉네임을 입력하면 블로그 글을 자동으로 불러옵니다.  
‘커밋’ 버튼만 누르면 해당 글이 GitHub 저장소에 커밋으로 기록됩니다.

### 2. 잔디 달력 시각화  
- 일반 코드 커밋: 초록색  
- 블로그 커밋(Huggit 커밋): 파란색  
커밋 빈도에 따라 색이 진해지며, 블로그와 코드 커밋을 한눈에 구분할 수 있습니다.

### 3. 커밋 알림  
매일 푸시 알림으로 "1일 1커밋" 습관을 도와줍니다. 잊지 않고 꾸준히 커밋하세요!

### 4. 스탬프 시스템  
연속 커밋 일수를 달성할 때마다 스탬프를 획득할 수 있어, 꾸준한 커밋에 대한 동기부여를 제공합니다.
